# CISC 4900 - Applicant Tracking & Workflow Portal

## Project Overview
An enterprise-grade applicant tracking and review platform designed and built within Appian Community Edition. The system features dynamic intake forms, candidate record synchronizations, multi-step review process models, and administrative decision dashboards.
## System Architecture & Objects
- **Data Layer:** Appian Synced Records (`OIA Applicant Profile`, `OIA Position Requests`, `OIA Application Submission`)
- **Logic & Rules:** Appian SAIL Expression Rules, Validation Logic, and Query Records
- **Process Layer:** Automated intake routing, reviewer assignment, and status transition process models
- **Interface Layer:** Role-based three-pane split interfaces (Applicant Portal)
